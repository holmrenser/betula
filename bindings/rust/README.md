# betula-schema (Rust)

Serde types and validating parsers for the [betula](https://holmrenser.github.io/betula/) JSON
Schemas: sequences, alignments, phylogenetic trees, gene annotations, distance matrices, and BLAST
results.

```rust
let tree: betula_schema::Tree =
    betula_schema::parse_str(r#"{"name": "A", "length": 0.1, "children": []}"#)?;
```

Every schema title is a type in `betula_schema`. Use `parse` / `parse_str` rather than
`serde_json::from_*`: the types are generated by typify, which doesn't enforce every JSON Schema
keyword, so these validate against the schema itself (with the `jsonschema` crate) before
deserializing, and reject exactly what the schema rejects.

See [Getting started](https://holmrenser.github.io/betula/getting-started/) for the full API tour,
and the [schema pages](https://holmrenser.github.io/betula/schemas/) for each type. The types are
generated from the schemas; the version matches the schema `$id` versions.
